# Français 60 — زكرياء المحجوبي

منصة عربية–فرنسية شخصية وتفاعلية للتعلم خلال 60 يوما، الإصدار 2.0 — 3 نونبر 2026.

## مكونات الإصدار الجديد

- 60 درسا بالترتيب نفسه للخطة الأصلية.
- **1917 جملة فرنسية مترجمة إلى العربية**؛ في كل درس **31 أو 32 جملة** (أمثلة أساسية، و14 جملة إضافية مرتبطة بالدرس، و14 سؤالا مبنيا عليها، بعد حذف التكرارات).
- مفردات كل درس مترجمة مع أزرار للاستماع بالفرنسية.
- **10 تمارين لكل يوم = 600 تمرين**، من ستة أنواع:
  1. الاختيار من متعدد (تمرينان)
  2. إكمال الفراغ (تمرينان)
  3. ترتيب الكلمات (تمرينان)
  4. الترجمة والكتابة (تمرينان)
  5. الإملاء بالاستماع (تمرين واحد)
  6. كتابة موجهة بنموذج مرجعي (تمرين واحد)
- تصحيح فوري أثناء إدخال إجابات الكتابة، وتصحيح مسجل بعد الضغط على «تصحيح» مع النموذج الصحيح، والكلمات الناقصة أو المختلفة، وتفسيرات لبعض الأخطاء النحوية الشائعة.
- دفتر كتابة حرة خاص لكل يوم، يُحفظ تلقائيا ويعرض ملاحظات إرشادية مباشرة عن بعض الأنماط الخاطئة.
- لوحة تقدم وإحصاءات أسبوعية ونتائج تمارين وتقييم ذاتي للمحادثة والقراءة والاستماع والكتابة.
- تسجيل الإنجاز اليدوي، وتحديد الجمل المفضلة، وتصدير واستيراد ملف تقدم JSON.
- تصميم متجاوب مع الهواتف والشاشات الصغيرة، ووضع تطبيق PWA مع أيقونة للشاشة الرئيسية ودعم للفتح بلا إنترنت بعد اكتمال تخزين ملفات المنصة.

## مهم بخصوص التصحيح الآلي

المشروع موقع ثابت على GitHub Pages ولا يحتوي خادما أو نموذجا لغويا خارجيا. **التمارين ذات الإجابات المحددة** تُصحَّح آليا بمقارنتها مع جمل مرجعية مع شرح للفروق. أما **الكتابة الحرة** فالمصحح محلي ومحدود: يرصد بعض الأخطاء الشائعة مثل `Je suis 27 ans`، ومطابقة تصريفات `être` و`avoir` و`aller`، والاختصارات `à + le = au`، وتهجئة كلمات معروفة، ولكنه لا يفهم جميع المعاني أو يحكم بدقة على كل الجمل الصحيحة البديلة. غياب تحذير ليس ضمانا بصحة النص. لا ترسل نصوصك تلقائيا إلى أي خدمة خارجية.

## النشر لأول مرة على GitHub Pages

1. فك ضغط الحزمة، وافتح المجلد الناتج.
2. أنشئ مستودعا عاما (Public) على GitHub، مثلا `francais60-zakaria`.
3. ارفع **محتويات المجلد** مع الحفاظ على البنية السابقة. يجب أن يكون `index.html` في **جذر** المستودع، لا داخل مجلد إضافي.
4. اذهب إلى `Settings → Pages`.
5. اختر `Build and deployment → Deploy from a branch`، ثم `main` و`/(root)`، واضغط `Save`.
6. بعد إتمام النشر، افتح رابطك بصيغة `https://USERNAME.github.io/francais60-zakaria/` (استبدل USERNAME باسم حسابك).

### إذا كان لديك الإصدار السابق على GitHub

- احتفظ أولا بنسخة احتياطية من تقدمك، باستعمال زر «تصدير التقدم» في الإصدار السابق إن رغبت.
- استبدل `index.html` و`sw.js` و`manifest.webmanifest` وجميع الملفات المطابقة في `assets` بالنسخة الجديدة. **لا تحتفظ بملفي `app.js` أو `lessons.js` القديمين**.
- انتظر حتى يكتمل نشر GitHub Pages ثم حدّث الصفحة. إن ظهرت النسخة القديمة بسبب التخزين المؤقت، أغلق التطبيق وافتحه مجددا أو امسح بيانات الموقع عند الحاجة (بعد أخذ نسخة احتياطية).
- عند فتح الإصدار الجديد في المتصفح نفسه وعلى نفس النطاق، سيحاول نقل الإنجازات والملاحظات المحفوظة من الإصدار السابق بصورة تلقائية. لا يمكن استعادتها من هاتف آخر دون ملف النسخة الاحتياطية.

### رفع الملفات باستعمال iPhone

- الأفضل رفع المشروع كاملا مرة واحدة باستعمال حاسوب، لأن واجهة GitHub للهاتف قد لا تسمح برفع المجلدات دفعة واحدة.
- إن استعملت Safari على iPhone، فك ضغط الحزمة في تطبيق «الملفات»، وارفع الملفات الموجودة في الجذر عبر `Add file → Upload files`.
- لإنشاء مجلد `assets` على GitHub اكتب `assets/.gitkeep` في `Add file → Create new file`، واحفظ التغيير. ثم افتح مجلد `assets` وارفع جميع محتوياته من تطبيق «الملفات» عبر `Upload files`. بعد التأكد من اكتمال الرفع يمكنك حذف `.gitkeep` أو إبقاءه؛ لا يؤثر على المنصة.
- افحص الأسماء والأحرف وحالة الأحرف (مثل `lessons.js` لا `Lessons.js`).

## إضافة المنصة للشاشة الرئيسية على iPhone

1. افتح عنوان GitHub Pages عبر **Safari**، وليس من متصفح مدمج داخل تطبيق آخر.
2. اضغط زر المشاركة، ثم **إضافة إلى الشاشة الرئيسية**.
3. اختر «إضافة». ستظهر أيقونة `Français ZM` بين تطبيقات الهاتف.
4. استخدم التطبيق عادة. يحتاج النطق إلى صوت فرنسي مدعوم من الهاتف، وقد لا يتوفر دون اتصال وفقا لإعدادات الجهاز.

## حفظ التقدم والنسخ الاحتياطية

الإنجازات والإجابات ومحتوى دفتر الكتابة والمفضلة تُحفظ على هذا المتصفح عبر `localStorage`. لا تحتاج إلى تسجيل دخول، لكن حذف بيانات الموقع أو تغيير الجهاز قد يمحوها. انقلها عبر `تصدير التقدم` و`استرجاع التقدم` في لوحة المسار.

## الصيانة والتخصيص

- `assets/lessons.js`: جميع الدروس الـ60 والجمل والمفردات والاختبارات.
- `assets/app.js`: وظائف التصفح والحفظ والتصحيح والتدريبات.
- `assets/style.css`: الألوان والتصميم المتجاوب.
- `manifest.webmanifest`: اسم التطبيق وأيقونته ووضع عرضه.
- `sw.js`: الملفات المخزنة واسم ذاكرة التخزين المؤقت. عند نشر تعديلات كبيرة لاحقا غيّر اسم `CACHE` لتحديث النسخة المحفوظة.

هذا المشروع يعمل من ملفات ثابتة ولا يحتاج إلى خادم خلفي أو مفاتيح API.
