# Français 60 — منصة زكرياء المحجوبي

منصة عربية متجاوبة لتعلم اللغة الفرنسية خلال 60 يوما، مصممة للعمل من الهاتف كأنها تطبيق مستقل بعد نشرها على **GitHub Pages**.

## محتويات المنصة

- **لوحة تقدّم شخصية**: عدد الدروس المكتملة، سلسلة الإنجاز بالأيام، نتيجة الاختبارات القصيرة، تقدم الأسابيع التسعة، وتقييم ذاتي للاستماع والمحادثة والقراءة والكتابة.
- **60 درسا فعليا**: مفردات مترجمة، جمل وأمثلة، شرح ونصيحة، مهمة تطبيقية، قائمة تدريب، سؤال تفاعلي، ودفتر كتابي شخصي.
- **النطق الصوتي**: اضغط أيقونة الصوت قرب أي كلمة أو عبارة، باستعمال خاصية النطق الفرنسية المتاحة على الهاتف.
- **حفظ تلقائي محلي** لبيانات التقدم والملاحظات، مع إمكانية تصدير ملف JSON واسترجاعه.
- **دعم العمل بلا إنترنت** للملفات المخزنة بعد الزيارة الأولى، عبر Service Worker (يتطلب فتح الموقع عبر HTTPS من GitHub Pages).
- **تطبيق ويب قابل للإضافة للشاشة الرئيسية** (PWA) مع أيقونة خاصة.

## نشرها على GitHub Pages خطوة بخطوة

1. ادخل إلى [github.com](https://github.com/) وسجّل الدخول.
2. اضغط **New repository** وأنشئ مستودعا عاما، مثلا `francais-60-zakaria`.
3. فك ضغط ملف ZIP المرفق. ارفع **جميع محتويات مجلد `zakaria-french-60`** إلى **جذر المستودع**، وليس ملف `index.html` وحده. احتفظ بالبنية:

   ```text
   index.html
   manifest.webmanifest
   sw.js
   assets/
     app.js
     lessons.js
     style.css
     hero-france.svg
     illustration-*.svg
     icon.svg
     icon-180.png
     icon-192.png
     icon-512.png
   ```

4. من داخل المستودع افتح **Settings → Pages**.
5. تحت **Build and deployment** اختر **Deploy from a branch** ثم **main** و **/(root)** واضغط **Save**.
6. سيكون رابط موقعك عادة بالشكل: `https://USERNAME.github.io/francais-60-zakaria/`، واستبدل `USERNAME` باسم حسابك الحقيقي. قد يحتاج النشر بعض الوقت.

## إضافة المنصة إلى تطبيقات iPhone

1. افتح رابط GitHub Pages **من تطبيق Safari** (لا تفتحه داخل متصفح فيسبوك أو إنستغرام).
2. اضغط زر **المشاركة** في Safari.
3. اختر **إضافة إلى الشاشة الرئيسية — Add to Home Screen**.
4. اختر **إضافة — Add**، وستجد أيقونة «Français ZM» ضمن تطبيقات هاتفك.
5. عند الضغط على الأيقونة ستفتح المنصة مباشرة بواجهة التطبيق دون الحاجة إلى البحث عن الرابط.

## استعمال المنصة

- تاريخ الانطلاق الافتراضي **3 نونبر 2026**؛ يمكن تغييره من لوحة التقدم.
- يمكن فتح أي يوم من الأيام الستين في أي وقت.
- علّم عناصر قائمة التدريب ثم اضغط «أنهيت درس اليوم» لتسجيل إنجازه.
- النسبة الرئيسية = عدد الدروس المكتملة ÷ 60.
- نسبة الاختبارات = نسبة الإجابات الصحيحة من آخر إجابة مسجلة لكل درس تم اختباره، **وليست شهادة أو اختبار CEFR رسمي**.
- مستوى A1 الظاهر عبارة عن **مؤشر تقدم داخل المسار** وليس تصنيفا لغويا معتمدا.
- استعمل زر «تصدير نسخة احتياطية» بانتظام للحفاظ على سجلك، خاصة قبل مسح بيانات Safari أو تغيير الجهاز.

## تنبيهات تقنية مهمة

- التقدم يُحفظ فقط في **localStorage** داخل **نفس المتصفح والجهاز**. GitHub لا يخزن نتائج المستخدم، ولا تتم مزامنتها تلقائيا بين الأجهزة. لاستعادتها، صدر ملف JSON واستورده في النسخة الأخرى.
- بعد النشر على GitHub Pages يمكن فتح الموقع دون اتصال إذا تم تخزين ملفات التطبيق مسبقا، لكن الاستماع الصوتي يعتمد على توفر محرك نطق فرنسي في نظام الهاتف وقد يختلف عمله دون إنترنت.
- أول تحميل يحتاج الإنترنت. الخطوط المستوردة من Google Fonts اختيارية؛ عند عدم توفر الإنترنت تظهر خطوط النظام البديلة.
- عند إجراء تعديلات على ملفات الموقع مستقبلا، يُنصح بتغيير اسم `CACHE` في `sw.js` من `v1` إلى `v2` لضمان تحديث ملفات التطبيق المخزنة.
- لا تُرفع معلومات خاصة إلى خادم: ما تكتبه في دفتر الجمل يبقى في المتصفح المحلي إلا إذا صدّرت نسخة بنفسك.

## التخصيص

- تعديل شكل وألوان الموقع: `assets/style.css`.
- تعديل النصوص والأمثلة والاختبارات: `assets/lessons.js`.
- تعديل وظائف المنصة: `assets/app.js`.
- تعديل اسم التطبيق وأيقوناته: `manifest.webmanifest` وملفات `assets/icon*`.
